# Repository Census Engine

## Overview

Repository Census Engine is a Python application that analyzes software repositories and produces structured reports describing repository contents.

The system scans project folders, classifies files, summarizes repository composition, and exports analysis results.

---

## Features

- Repository scanning
- File classification
- Repository statistics
- Structured reporting
- JSON export
- Markdown report generation
- Desktop GUI interface

---

## Technologies

- Python
- JSON
- Markdown Reporting
- File System Analysis

---

## How It Works

1. Select a repository.
2. Scan files and folders.
3. Classify repository contents.
4. Generate repository statistics.
5. Export structured reports.
